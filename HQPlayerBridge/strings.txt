PLUGIN_HQPLAYER_BRIDGE
	EN	HQPlayer Bridge

PLUGIN_HQPLAYER_BRIDGE_DESC
	EN	Presents each HQPlayer instance on your network as an ordinary Lyrion player, driven directly over HQPlayer's own control API. No UPnP bridge and no helper in the playback path: HQPlayer fetches the stream straight from Lyrion, so the plugin adds no audio stage of its own. Most of your library is handed over untouched, but Lyrion does still convert formats HQPlayer cannot decode, such as ALAC and AAC. A bit-perfect mode on each player's HQPlayer page removes everything on Lyrion's side that could alter the stream. Instances are discovered automatically - or, with discovery switched off in the settings, taken from IP addresses you enter.
	FR	Présente chaque instance HQPlayer du réseau comme un lecteur Lyrion ordinaire, piloté directement par l'API de contrôle d'HQPlayer. Ni pont UPnP ni intermédiaire dans le chemin audio : HQPlayer récupère le flux directement auprès de Lyrion, le plugin n'ajoute aucun étage audio. La plupart de votre bibliothèque est transmise intacte, mais Lyrion convertit encore les formats qu'HQPlayer ne sait pas décoder, comme ALAC et AAC. Un mode bit-perfect, dans la page HQPlayer de chaque lecteur, supprime tout ce qui, côté Lyrion, pourrait modifier le flux. Les instances sont découvertes automatiquement - ou, découverte désactivée dans les réglages, prises dans les adresses IP que vous saisissez.

PLUGIN_HQPLAYER_BP_TITLE
	EN	Bit-perfect mode
	FR	Mode bit-perfect

PLUGIN_HQPLAYER_BP_DESC
	EN	Hands HQPlayer the source exactly as it is. While on: no ReplayGain is applied (unity is sent, overriding the file's own tags), Lyrion's bitrate limit is held at none so nothing is turned into MP3, and Lyrion's volume control is set to fixed so the slider no longer moves HQPlayer. Switching it on also sets HQPlayer's volume to 0 dB once; HQPlayer's own volume stays yours to change afterwards. Switching it off puts Lyrion's volume control back as it was. HQPlayer's own processing - upsampling, filters, modulation - is not affected.
	FR	Transmet la source à HQPlayer telle quelle. Une fois activé : aucun ReplayGain n'est appliqué (un gain unitaire est envoyé, qui prend le pas sur les tags du fichier), la limite de débit de Lyrion est maintenue à « aucune » pour que rien ne soit converti en MP3, et le contrôle du volume de Lyrion passe en fixe : le curseur ne pilote plus HQPlayer. L'activation règle aussi une fois le volume d'HQPlayer à 0 dB ; vous restez libre de le changer ensuite dans HQPlayer. La désactivation rétablit le contrôle du volume de Lyrion tel qu'il était. Le traitement d'HQPlayer lui-même - suréchantillonnage, filtres, modulation - n'est pas modifié.
